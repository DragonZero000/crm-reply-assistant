# mock-chat-ui Specification

## Purpose
Mock-режим интеграции: HTML-страница, имитирующая чат сделки через тот же вебхук в amo-формате, и чтение диалога и примечаний сделки.

## Requirements
### Requirement: Страница mock-чата
В режиме `CRM_MODE=mock` система SHALL отдавать по `GET /mock` одну HTML-страницу без сборки и внешних зависимостей: поле номера сделки, переключатель отправителя «клиент / менеджер», поле ввода сообщения, лента диалога и список примечаний сделки. Страница MUST отправлять сообщения в `POST /webhooks/amo` в том же form-urlencoded формате, что и amoCRM (`type=incoming` для клиента, `type=outgoing` для менеджера, уникальный id сообщения).

#### Scenario: Сообщение клиента со страницы
- **GIVEN** открыта `/mock`, выбрана сделка `555` и отправитель «клиент»
- **WHEN** пользователь отправляет «Сколько стоит доставка?»
- **THEN** на `/webhooks/amo` уходит вебхук с `type=incoming`, `entity_type=lead`, `entity_id=555`, а после генерации на странице появляется примечание с черновиком и подсказкой

#### Scenario: Сообщение менеджера со страницы
- **GIVEN** выбран отправитель «менеджер»
- **WHEN** пользователь отправляет «Могу добавить витамин D3»
- **THEN** сообщение появляется в ленте диалога, новое примечание не создаётся

#### Scenario: Вопрос вне базы знаний
- **WHEN** клиент со страницы спрашивает о товаре, которого нет в базе
- **THEN** появившееся примечание показывает, что нужен менеджер, потому что ответа нет в базе знаний

#### Scenario: Ожидание генерации
- **WHEN** сообщение клиента отправлено, а примечание ещё не готово
- **THEN** страница показывает индикатор ожидания и продолжает опрашивать сервер, пока не появится новое примечание

### Requirement: Чтение диалога и примечаний сделки
В режиме `CRM_MODE=mock` система SHALL отдавать по `GET /mock/leads/{lead_id}` JSON с историей сообщений сделки (роль, текст) и примечаниями из `MockCrmClient` (текст, время создания) в порядке создания. Для сделки без данных MUST возвращаться пустые списки, а не ошибка.

#### Scenario: Сделка с примечанием
- **GIVEN** по сделке `555` было одно сообщение клиента и создано одно примечание
- **WHEN** запрошен `GET /mock/leads/555`
- **THEN** ответ содержит одно сообщение с ролью `client` и одно примечание

#### Scenario: Неизвестная сделка
- **WHEN** запрошен `GET /mock/leads/999`
- **THEN** ответ `200` с пустыми списками сообщений и примечаний

### Requirement: Mock-эндпоинты только в mock-режиме
При `CRM_MODE=amo` эндпоинты `/mock` и `/mock/leads/{lead_id}` MUST NOT быть доступны.

#### Scenario: Режим amo
- **GIVEN** `CRM_MODE=amo`
- **WHEN** запрошен `GET /mock`
- **THEN** сервис отвечает `404`
