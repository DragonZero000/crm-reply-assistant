## MODIFIED Requirements

### Requirement: Покрытие утверждений о лечебном действии
Стоп-лист SHALL ловить утверждения о лечебном действии товара, построенные как «действие + медицинский объект» или «лечебное свойство», а не только глаголы «лечит»/«вылечит». Каждое правило MUST описывать фразу, а не голую основу слова. Правило «помогает при …» MUST срабатывать только в сочетании с названием болезни, симптома или состояния здоровья; правило MUST срабатывать и тогда, когда между «при» и этим названием стоят до двух слов («при головной боли», «при регулярных головных болях»). Стоп-лист MUST NOT срабатывать на инструкции по приёму, условия доставки и оплаты, рекомендацию проконсультироваться с врачом, шаблоны ответов и тексты базы знаний.

#### Scenario: Снятие симптома
- **GIVEN** загруженный стоп-лист
- **WHEN** проверяется текст «Этот массажёр снимет боль в суставах»
- **THEN** есть срабатывание с найденным фрагментом «снимет боль»

#### Scenario: «Поможет при» болезни
- **GIVEN** загруженный стоп-лист
- **WHEN** проверяется текст «Цинк поможет при простуде»
- **THEN** есть срабатывание

#### Scenario: «Помогает при» с определением перед симптомом
- **GIVEN** загруженный стоп-лист
- **WHEN** проверяются тексты «Помогает при головной боли» и «Поможет при регулярных головных болях»
- **THEN** каждый текст вызывает срабатывание правила `helps_with_condition`

#### Scenario: Лечебный или оздоравливающий эффект
- **GIVEN** загруженный стоп-лист
- **WHEN** проверяются тексты «Обладает лечебным эффектом» и «Курс оздоровит организм»
- **THEN** каждый текст вызывает срабатывание

#### Scenario: Нормализация показателей
- **GIVEN** загруженный стоп-лист
- **WHEN** проверяются тексты «Нормализует давление» и «Омега-3 снижает холестерин»
- **THEN** каждый текст вызывает срабатывание

#### Scenario: Эффективность против болезни
- **GIVEN** загруженный стоп-лист
- **WHEN** проверяется текст «Коллаген эффективен против артрита»
- **THEN** есть срабатывание

#### Scenario: Приём для лечения
- **GIVEN** загруженный стоп-лист
- **WHEN** проверяется текст «Принимайте для лечения гастрита»
- **THEN** есть срабатывание

#### Scenario: «Помогает при» без медицинского слова
- **GIVEN** загруженный стоп-лист
- **WHEN** проверяется текст «Менеджер помогает при выборе размера»
- **THEN** срабатываний нет

#### Scenario: «Помогает при» с несколькими словами без медицинского слова
- **GIVEN** загруженный стоп-лист
- **WHEN** проверяется текст «Помогает при выборе размера шейкера»
- **THEN** срабатываний нет

#### Scenario: Инструкции, доставка и рекомендация врача
- **GIVEN** загруженный стоп-лист
- **WHEN** проверяются тексты «Принимать по 1 капсуле 2 раза в день во время еды», «Доставка от 2 до 7 рабочих дней» и «При заболеваниях проконсультируйтесь с врачом»
- **THEN** срабатываний нет

#### Scenario: Ответа нет в базе знаний
- **GIVEN** загруженный стоп-лист
- **WHEN** проверяется типичный черновик на вопрос вне базы «Уточню этот вопрос у специалиста и вернусь с ответом»
- **THEN** срабатываний нет, черновик не заменяется и `reason` от модели (`no_kb_answer`) сохраняется

#### Scenario: Новые правила не срабатывают на базе знаний
- **GIVEN** загруженные база знаний и стоп-лист с новыми правилами
- **WHEN** каждое текстовое поле каждой записи базы проверяется стоп-листом
- **THEN** срабатываний нет
